# Ejemplos de Texto Markdown

Este documento muestra ejemplos de texto formateado en Markdown.

## Texto tachado

Puedes usar texto ~~tachado~~ con la sintaxis de tildes dobles.

### Ejemplos:

- ~~Texto eliminado~~
- Este es un ~~error~~ a corregir
- ~~Versión antigua~~ Nueva versión

## Texto destacado

Puedes usar **texto en negrita** o *texto en cursiva*.

- **Negrita fuerte**
- *Cursiva suave*
- ***Negrita y cursiva***
- `Código en línea`
